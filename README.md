# The Masonic Order of Saint Patrick — Ritual Presentation

This repository holds the source for a standalone HTML ritual presentation for the Masonic Order of Saint Patrick.

## Live website

[Visit the Masonic Order of Saint Patrick website](https://webappngdsib.github.io/St-Patrick/)

The public website covers the Order’s history, its relationship with the Allied Masonic Degrees, admission requirements, symbols, lodges, Grand Lodge officers and honours, and contact information.

## Ritual presentation

- [Source file](index.html)
- [GitHub Pages address for this repository](https://webappngdsib.github.io/Saint-Patrick-RITUAL-/)

GitHub Pages is configured to publish from the root of `main`. The presentation URL currently returns 404. The supplied `index.html` ends partway through a CSS media query. A complete HTML file is needed to render the presentation.

The presentation source uses HTML and inline CSS. Once the complete file is available, open `index.html` in a browser to preview it locally. No build step is required.
