# The Masonic Order of Saint Patrick — Ritual Presentation

This repository holds the source for a standalone HTML ritual presentation for the Masonic Order of Saint Patrick.

## Live website

[Visit the Masonic Order of Saint Patrick website](https://webappngdsib.github.io/St-Patrick/)

The public website covers the Order’s history, its relationship with the Allied Masonic Degrees, admission requirements, symbols, lodges, Grand Lodge officers and honours, and contact information.

## Ritual presentation

- [Source file](index.html)
- [View the ritual presentation](https://webappngdsib.github.io/Saint-Patrick-RITUAL-/)

The presentation includes the Lodge chamber and officers guide and the English ritual from opening through closing. Select an officer role to highlight and navigate to that officer’s parts.

GitHub Pages publishes from the root of `main`. To preview locally, open `index.html` in a browser. The page uses HTML, CSS, and JavaScript with no build step. An internet connection is needed to load the Google Fonts.
