# Public diary entries

Use **New entry** on [Saint Patrick Diary](https://webappngdsib.github.io/Saint-Patrick-RITUAL-/diary.html) to prepare the event and up to three photographs. Download the generated JSON file, upload it to this directory on `main`, and commit it. Entries appear on the public diary after GitHub Pages deploys.

Each file is a JSON array with one or more records. A record has a `date` (YYYY-MM-DD), `location`, `chamber`, and a `photos` array with up to three image data URLs. The diary's export button can prepare a file for entries previously saved in the current browser.
